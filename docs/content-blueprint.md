# Nimble Pay Website Content Blueprint

Documento base para crear una web tipo UpNexa, pero adaptada a **Nimble Pay**: moderna, premium, tecnológica, directa y enfocada en ayudar a negocios a cobrar mejor, reducir fees y operar con sistemas POS modernos.

## Objetivo principal de la web

La web debe convertir visitantes en leads para una consulta o demo.

Nimble Pay debe comunicar rápido que ayuda a restaurantes, bares, tiendas y negocios de servicios a:

* Aceptar pagos con tarjeta, contactless y wallets digitales.
* Reducir o eliminar costos de procesamiento de tarjetas.
* Instalar sistemas POS modernos con hardware incluido o preconfigurado.
* Recibir soporte real, local y en español.
* Empezar a cobrar rápido con una solución lista para operar.
